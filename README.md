
# 🛒 Sistema de Gestión de Productos

Trabajo final del curso de Python.

Este proyecto es una aplicación de consola para gestionar productos de un inventario.

---

## 📌 ¿Qué hace el programa?

El programa permite:

* ➕ Agregar productos
* 📋 Ver todos los productos cargados
* 🔎 Buscar productos por nombre
* ✏️ Actualizar productos
* 🗑️ Eliminar productos
* ⚠️ Ver productos con bajo stock

Los datos se guardan en una base de datos SQLite llamada `inventario.db`, por eso no se pierden cuando cierro el programa.

---

## 🛠️ Tecnologías usadas

* Python
* SQLite3

---

## ▶️ Cómo ejecutar el programa

Abrir la terminal en la carpeta del proyecto y escribir:

```bash
py entregaFinal.py
```
